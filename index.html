A 5-card site like Austin's wedding receipts, built from your own iMessage or WhatsApp history. Runs entirely on your laptop. Your messages never leave your machine.

What you need

  • 30 minutes.
  • A laptop — macOS, Windows, or Linux. (iMessage requires a Mac. WhatsApp works anywhere.)
  • Either Claude Code (free trial works) or Ollama with a 14B local model.
  • Your chat history — exported using the steps below.

Step-by-step

1. Install Claude Code

npm install -g @anthropic-ai/claude-code
claude

If you don't have Node yet: install Node.js first (the LTS download is fine). On the first run, claude will guide you through login — a free trial works.

2. Get your chat history

iMessage — sign into iCloud + Messages on your Mac (System Settings → Apple ID → iCloud → Messages on iCloud → on). Wait a minute for sync, then:

cp ~/Library/Messages/chat.db ~/Desktop/chat.db

If permission denied: System Settings → Privacy & Security → Full Disk Access → toggle Terminal on, then re-run.

WhatsApp — on your iPhone open the chat → tap the contact name → Export Chat → Without Media → AirDrop or email the .zip to your Mac.

3. Unzip the kit and drop your chat into it

cd ~/Downloads
unzip the-receipts-kit.zip
cd the-receipts-kit
mv ~/Desktop/chat.db .            # or:  mv ~/Downloads/WhatsApp*.zip .
claude

4. Paste this prompt

If you downloaded the starter kit, this same prompt is in prompt.md — same content, easier to paste.

Read the chat file in this folder (chat.db for iMessage, or unzip the WhatsApp zip and read _chat.txt). For iMessage: list all chats with at least 50 messages, sorted by message count, and ask me which one to use. For WhatsApp: just use the conversation in the export. Then build a single self-contained HTML file called receipts.html with 5 swipeable cards: 1. The receipts — hero stats: total messages, days, photos, videos, emojis, "I love you" count, and a sender split bar. 2. The shape of us — bar chart of messages per week (or per month if dataset is short), with the peak bar highlighted in orange. 3. Around the clock — 7 weekdays × 24 hours heatmap, shaded by volume, with the peak bucket called out. 4. The vocabulary — "I love you" count + top 9 emojis grid. 5. The arc — first message, peak day, peak month, longest unbroken streak. Match the aesthetic of the reference images in this folder: reference/01-receipts.png, reference/02-shape.png, reference/03-clock.png, reference/04-vocabulary.png. Cream paper background (#F1E9D2), sage green double scalloped border, handwritten cursive titles (Snell Roundhand / Apple Chancery / Brush Script MT / cursive fallback), monospace numbers, small caps labels. Orange accent (#D58A4A) for the peak bar / peak callouts. Dark page background outside the card. Heart icon in the bottom-right of each card. Cards swipeable with arrow keys, click zones, and touch. Constraints: single HTML file with all data inlined as a JS object. No external CDN. No build step. No telemetry. Works offline. Add a Content-Security-Policy meta tag with connect-src 'none' so the file cannot make network requests. For "I love you" detection use a regex covering: i love you, i love u, love you, love u, ily, ilu — and add Telugu (premistunna, premistunnanu) or Hindi (pyaar karta hoon, pyaar karti hoon) variants if the chat looks like that language. Handle iOS 16+ messages where text is NULL and the real body is in attributedBody (binary plist) — decode the NSString payload from those blobs. Use UTC for the day-streak comparison so DST changes don't break the streak. Handle skin-tone modifiers (U+1F3FB–U+1F3FF) and ZWJ sequences in emoji counting.

Open-source path · Ollama, no Anthropic key

Same end product. Runs on a local model. Slower, fully offline, no account needed.

Install Ollama

macOS / Linux:

curl -fsSL https://ollama.com/install.sh | sh

Windows: download the installer from ollama.com.

Pull a coding model

ollama pull qwen2.5-coder:14b      # ~9 GB, best balance
# or, if you have less RAM:
ollama pull qwen2.5-coder:7b       # ~4.7 GB
# or, for stronger code:
ollama pull deepseek-coder-v2:16b  # ~9 GB

Pick a CLI to drive it

Option A — Aider (mature, works everywhere):

pip install aider-chat
cd ~/receipts
aider --model ollama_chat/qwen2.5-coder:14b

Option B — opencode (Claude-Code-style TUI, supports Ollama):

npm install -g opencode-ai
cd ~/receipts
opencode

Inside opencode pick Ollama → qwen2.5-coder:14b.

Why it works

The actual analysis is dumb math: count messages, group by hour, regex for emojis. The model only writes a parser, runs it, and templates an HTML file — all well within a 14B local model's capability. No agentic acrobatics needed.

Privacy

Your messages never leave your machine.
  • Claude Code only sends the text you type plus the code it writes — not raw file contents — unless you explicitly attach a file. Even then, you control what goes in.
  • The Ollama path is fully offline. Disconnect your network and verify.
  • The output is a single HTML file. Share as-is, or ask Claude to add a password layer (AES-GCM via WebCrypto) before sharing.

Tips

  • iMessage on iOS 16+ stores some message text in attributedBody (a binary plist). If your script is missing messages, ask Claude: "decode attributedBody NSAttributedString blobs."
  • Couples / weddings — for an Austin-style guest site, ask Claude to add per-year narrative summaries. That's where LLMs really shine.
  • Short datasets — if you only have months of history, use messages-per-week instead of per-year.
  • Other languages — for "I love you" in Hindi, Spanish, Telugu, etc., add the phrase variants to the regex. Just ask Claude.
  • WhatsApp Android — the export format is slightly different (dashes instead of brackets). Claude handles both, but mention it if your output looks empty.
  • Encrypted share — "Add a password unlock screen using WebCrypto AES-GCM with PBKDF2-derived key. Recipient enters password to view."
